# 師培教學資源

收納師培教材、反思學習教練指令與情境判斷練習資源，供後續持續新增與修訂。

## 目前使用版本

- [NotebookLM｜師培生反思學習教練 v1.0 情境轉化修正版](reflection-coach/NotebookLM_師培生反思學習教練_v1.0_情境轉化修正版.md)：以最初 v1.0 為基礎，保留原流程、提問與卡片格式，融入情境條件變化後的判斷練習。

## 其他版本

- [v1.2 擴充版](reflection-coach/NotebookLM_師培生反思學習教練_v1.2.md)：保留供參考。

## 使用方式

開啟資源檔，依其中「學生使用方式」與「Custom instructions」設定。下載單一檔案時，可在 GitHub 檔案頁面使用「Download raw file」。上傳教學紀錄前，請處理可識別資訊並確認分享權限。

情境轉化修正版尚未在 NotebookLM 實測。

## 收納方式

- `reflection-coach/`：反思學習教練與相關指令文件。
- 日後依用途新增教材與情境練習資料夾；檔名保留版本號，方便追蹤修訂。
