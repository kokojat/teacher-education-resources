# 師培教學資源

收納師培教材、反思學習教練指令與情境判斷練習資源，供後續持續新增與修訂。

## 現有資源

- [NotebookLM｜師培生反思學習教練 v1.2](reflection-coach/NotebookLM_師培生反思學習教練_v1.2.md)：含理論閱讀、教學反思、教學準備、情境判斷與轉化訓練，以及來源比較與證據檢核。

## 使用方式

開啟資源檔，依其中「學生使用方式」與「Custom instructions」設定。上傳教學紀錄前，請處理可識別資訊並確認分享權限。

目前版本為修訂建議，尚未在 NotebookLM 實測。

## 收納方式

- `reflection-coach/`：反思學習教練與相關指令文件。
- 日後依用途新增教材與情境練習資料夾；檔名保留版本號，方便追蹤修訂。
